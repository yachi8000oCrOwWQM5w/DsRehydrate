## 四、合规红线（这些别写进文案）

1. **不要写"破解""解除限额""无限额度""绕过限制"**——既做不到，也容易被举报下架。
2. **不要索要对方账号密码**。导出必须买家自己做，这是唯一干净的边界。
3. **别写"虚拟商品售出不退"**这种绝对化表述，容易判违规。改成"确认能接上话再确认收货"。
4. 描述里不要出现微信/QQ 号引流，闲鱼会限流。
5. 涉及"角色扮演"的内容，别往擦边方向写。真要接这类单，私聊也别承诺内容尺度。

## 九、发给客户的导出教程

配套图：`tutorial.png`（1080×1350，聊天窗口里竖图，手机上能直接读）

**第一句话术**（发图之前或同时发）：

```
导出很简单，三步，电脑上做——手机 App 里没有这个入口。

1. 电脑浏览器打开 chat.deepseek.com，用你平时那个号登录
2. 点左下角头像 → 设置 → 数据管理 → 导出所有历史对话
3. 等它打包好（几十秒到几分钟），下载下来的 ZIP 存桌面

⚠️ 导完别删那个对话，它是原件
⚠️ ZIP 不用发给我，我全程看你屏幕，不碰文件

卡在哪一步就截图给我，别自己乱点删除。
```

**为什么这么写**：

- 开头先说"手机上没有"，因为十个人里有八个先在手机上找，找不到就以为是自己不会用，直接不买了。
- "找不到不是你的问题"这句话放在图上，是替客户卸责——他一旦觉得自己笨，就会放弃。
- 单独强调"ZIP 不用发我"，是把风险讲在前面。他反而更放心，因为这证明你不想要他的数据。
- 最后一句"别自己乱点删除"是保命：真有人为了"重新导一次"把原对话删了，那就真没了。

**客户如果回"我找不到设置"**：

先问他是手机还是电脑。手机就让他换电脑；电脑就让他把整页截图发来——多半是浏览器缩放导致左下角头像被挤出可视区，Ctrl+0 恢复 100% 就出来了。
